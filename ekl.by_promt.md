## 1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

**Название:** ekl.by  
**Тип:** SaaS-приложение для проектирования монтажных электрических схем  
**Целевая аудитория:** Электрики, проектировщики, монтажники  
**Основная задача:** Создание, редактирование и экспорт электрических схем с возможностью трассировки проводов

### 4.1 АВТОРИЗАЦИЯ

**Вход только по номеру телефона + SMS-код**

#### 4.1.1 Экран входа (первый экран)

```
┌─────────────────────────────────────────────────────────────────────┐
│  📱 ekl.by                                                         │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  🔐 ВХОД В СИСТЕМУ                                         │   │
│  │                                                             │   │
│  │  Введите номер телефона:                                    │   │
│  │  📞 [ +375 (29) 123-45-67 ]                                │   │
│  │                                                             │   │
│  │  [📨 Получить код]                                          │   │
│  │                                                             │   │
│  │  Введите код из SMS:                                       │   │
│  │  [ _ ][ _ ][ _ ][ _ ][ _ ][ _ ]                            │   │
│  │                                                             │   │
│  │  [✅ Войти]                                                 │   │
│  │                                                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────┘
```

**Правила:**
- Автоматическая регистрация (новый номер = новый аккаунт)
- Сессия 7 дней (JWT-токен)
- При неактивности 7 дней — автоматический выход
- Повторная отправка кода через 60 секунд
- Максимум 5 попыток ввода кода → блокировка на 5 минут
- Автопереход на следующее поле при вводе цифры

#### 4.1.2 Режим разработки (Dev)

**SMS не отправляется!** Код выводится в консоль терминала:
```
📱 [DEV MODE] SMS-код для +375 29 111-11-11: 123456
```

**В админ-панели (только Dev):**
- Кнопка `🔐 Войти в АДМИН-ПАНЕЛЬ без SMS` — выбор администратора → вход в админку
- Кнопка `✏️ Войти в РЕДАКТОР без SMS` — выбор пользователя → вход в редактор

#### 4.1.3 Верхняя панель (всегда видна)

```
┌─────────────────────────────────────────────────────────────────────┐
│  📱 ekl.by                                      📞 +375 29 123-45-67│
├─────────────────────────────────────────────────────────────────────┤
```

**Правила:**
- Слева: логотип "ekl.by"
- Справа: номер телефона (или имя, если пользователь ввёл)
- Клик по номеру → выпадающее меню:
  - Поле "Имя" (можно редактировать)
  - Номер телефона (только просмотр)
  - "Выйти"

### 4.9 ТРАССИРОВКА ПРОВОДОВ

#### 4.9.1 Режимы трассировки

| Режим | Описание |
|-------|----------|
| **Одиночная** | Клик на первой клемме → клик на второй → провод построен |
| **Ведомственная** | Клик → промежуточные точки → клик на конечной |
| **Шинопровод** | Выделить несколько клемм → построить шину |

#### 4.9.2 Правила соединения

| Откуда | Куда | Результат |
|--------|------|-----------|
| Выход | Вход | ✅ Разрешено |
| Выход | Выход | ❌ Ошибка (визуальная) |
| Вход | Вход | ❌ Ошибка (визуальная) |
| Вход | Выход | ✅ Разрешено |

#### 4.9.3 Визуальная обратная связь

**Правильное соединение:**
- Точка подсвечивается зелёным
- Провод прорисовывается анимированно (0.5 сек)

**Неправильное соединение:**
- Красная вспышка на точке (0.3 сек)
- Точка моргает красным (2 раза)
- Всплывающий toast: "Нельзя соединить Выход с Выходом"
- Toast исчезает через 1.5 секунды
- Провод исчезает (действие отменено)

### 4.13 КОПИРОВАНИЕ И ВСТАВКА

| Действие | Горячая клавиша | Куда вставляется |
|----------|-----------------|------------------|
| **Копировать + Вставить** | Ctrl+C → Ctrl+V | В точку курсора |
| **Дублировать** | Ctrl+D | Смещение +20, +20 |

#### 4.13.1 Вырезать (Ctrl+X)

- Объекты удаляются с холста
- Помещаются в буфер обмена
- Провода к внешним объектам — обрываются

#### 4.13.2 Копировать (Ctrl+C)

- Объекты копируются в буфер
- Провода между скопированными — сохраняются
- Провода к внешним — не копируются

#### 4.13.3 Вставить (Ctrl+V)

- Объекты вставляются в точку курсора
- Провода между вставленными — сохраняются
- Провода к внешним — обрываются

#### 4.13.4 Дублировать (Ctrl+D)

- Объекты копируются со смещением +20, +20
- Провода между дублированными — сохраняются
- Провода к внешним — обрываются

| Сценарий | Результат |
|----------|-----------|
| Удалён компонент, провода НЕ выделены | Провода становятся висячими |
| Удалён компонент + провода выделены | Провода удаляются вместе |
| Удалены только провода | Провода удаляются, компоненты остаются |
| Удалена группа | Удаляются все объекты в группе |

```
│                                                                     │
│  К этому компоненту подключены провода.                           │
│  Они станут висячими (будут обрублены).                           │
│                                                                     │
│  [Удалить только компонент]  [Удалить компонент + провода]        │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.19 СХЕМА БАЗЫ ДАННЫХ (PostgreSQL)

```sql
-- Пользователи
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  phone TEXT UNIQUE NOT NULL,
  name TEXT,
  role TEXT DEFAULT 'user',
  banned BOOLEAN DEFAULT FALSE,
  ban_reason TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  last_active TIMESTAMP DEFAULT NOW()
);

-- Администраторы (отдельная таблица)
CREATE TABLE admins (
  id UUID PRIMARY KEY REFERENCES users(id),
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Токены
CREATE TABLE auth_tokens (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  token TEXT NOT NULL,
  expires_at TIMESTAMP NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Проекты
CREATE TABLE projects (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  data JSONB NOT NULL,
  thumbnail TEXT,
  last_opened TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Компоненты (библиотека)
CREATE TABLE components (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  article TEXT,
  brand_id UUID REFERENCES brands(id),
  category_id UUID REFERENCES categories(id),
  type TEXT,
  image_url TEXT,
  terminals JSONB NOT NULL,
  params JSONB,
  active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Категории
CREATE TABLE categories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  parent_id UUID REFERENCES categories(id),
  sort_order INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Бренды
CREATE TABLE brands (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  logo_url TEXT,
  website TEXT,
  active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Шаблоны
CREATE TABLE templates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  category TEXT,
  thumbnail TEXT,
  data JSONB NOT NULL,
  is_default BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Избранное (пользователи)
CREATE TABLE user_favorites (
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  component_id UUID REFERENCES components(id) ON DELETE CASCADE,
  sort_order INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  PRIMARY KEY (user_id, component_id)
);

-- Аудит (админ-логи)
CREATE TABLE admin_audit (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  admin_id UUID REFERENCES users(id),
  action TEXT NOT NULL,
  details JSONB,
  ip TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Индексы
CREATE INDEX idx_projects_user_id ON projects(user_id);
CREATE INDEX idx_projects_last_opened ON projects(last_opened DESC);
CREATE INDEX idx_projects_updated_at ON projects(updated_at DESC);
CREATE INDEX idx_components_brand_id ON components(brand_id);
CREATE INDEX idx_components_category_id ON components(category_id);
CREATE INDEX idx_components_active ON components(active);
CREATE INDEX idx_auth_tokens_token ON auth_tokens(token);
CREATE INDEX idx_auth_tokens_expires_at ON auth_tokens(expires_at);
CREATE INDEX idx_admin_audit_admin_id ON admin_audit(admin_id);
CREATE INDEX idx_admin_audit_created_at ON admin_audit(created_at DESC);
```

## 5. КЛЮЧЕВЫЕ ОСОБЕННОСТИ РЕАЛИЗАЦИИ

### 5.1 Dev-режим (локальное тестирование)
- SMS не отправляется, код выводится в консоль (`123456`)
- В админ-панели две кнопки тестового входа:
  - `🔐 Войти в АДМИН-ПАНЕЛЬ без SMS`
  - `✏️ Войти в РЕДАКТОР без SMS`

### 5.2 Prod-режим (облачный сервер)
- Полноценная отправка SMS через API-шлюз
- Кнопки тестового входа скрыты
- Полная защита кода (обфускация, минификация)

### 5.3 JointJS
- Бесплатная версия (MIT)
- Локально: `C:\Users\wantt\Downloads\joint-master`
- Используется для холста, компонентов, проводов, трассировки

### 5.4 Безопасность
- Бан пользователей с причиной
- Защита от скриншотов (белый экран)
- Обфускация кода
- Rate Limiting

## 6. ТРЕБОВАНИЯ К ИНТЕРФЕЙСУ

1. **Адаптация только под компьютер** (мин. 1280×720)
2. **Тёмная/светлая тема** (переключение)
3. **Минимальные анимации** (200–300ms, без задержек)
4. **Все элементы интерактивны** (подсказки, превью, обратная связь)
5. **Как в AutoCAD:**
   - Масштабирование к курсору
   - ORTHO (F8)
   - Выделение: окно (синее) и перекрестие (зелёное)
   - Панорамирование (колесо + drag)
